# Кандидат исправления полноты перевода · 22 сентября 2026

Статус: **repair candidate; полная повторная приёмка не пройдена**.
Baseline ядра: `6634ac4781469d9f913ebdd550c3774eba9bc2e5`.

## Что воспроизведено

Опубликованный браузерный RTE вернул для `The train arrives at 10:30. Please bring two tickets.` только `Поезд прибывает в РТЕЙНВ0ТОКЕН.`. Результат совпадает с прежним протоколом. В утверждённую память тестовые пары не принимались.

Старый код склеивал два коротких предложения в один вызов модели и принимал потерянные/искажённые маски. Это воспроизводимые механизмы дефекта; они не объясняют все возможные ошибки модели.

## Изменения

- Каждое предложение переводится отдельно; разделители строк и абзацев сохраняются. Длинные предложения делятся по пробелам, неделимые токены не разрезаются.
- Время `10:30` защищается целиком. Известное кириллическое написание маркера восстанавливается только по точному ID.
- Потерянный, повторённый или неизвестный маркер отклоняет кандидата. Плохие варианты исключаются по отдельности.
- Если нет защищаемого термина словаря, разрешён один повтор на исходном предложении без масок. Принимается только точное совпадение множества и количества защищаемых значений, включая время. При неуспехе готовый перевод не выдаётся.
- При защищаемом словаре такого повтора нет: неподтверждённая терминология не проходит обходным путём.
- При сборке документа отсутствующий сегмент не превращается в пустую строку. Нечёткое совпадение памяти не подставляется как готовый перевод другого исходника.
- Старая выдача очищается перед новой попыткой, ввод блокируется на время расчёта, служебные маски нельзя принять в память.

## Живая проверка моделей

Среда: Node.js 24.19.0, Transformers.js 3.7.2, ONNX CPU q8; модели `Xenova/opus-mt-en-ru` и `Xenova/opus-mt-ru-en`. Это реальная нейронная генерация, но **не браузерная WASM/iPhone-приёмка**. Исходные и новые вызовы выполнялись на одинаковых входах. Общий режим — три кандидата, beams=4, do_sample=false; библиотека фактически возвращала одну форму. Ограниченный повтор — одна форма, beams=2. Точные запросы, параметры и ответы сохранены в [fixture](../tests/fixtures/neural-20260922.json).

| Вход | Результат кандидата |
|---|---|
| The train arrives at 10:30. Please bring two tickets. | Поезд прибывает в 10:30. Пожалуйста, принесите два билета. |
| The meeting starts at 09:15. Bring 3 copies. | Заседание начинается в 09:15. Принесите копии 3. |
| Send the report to mail@example.com. The code is 42. | Отправьте отчет в mail@example.com. Код - 42. |
| Сегодня хорошая погода. Мы идём в парк. | It's good weather today. We're going to the park. |
| Встреча начинается в 09:15. Принесите 3 копии. | Отказ: модель в повторе выдала 0915 вместо 09:15; документ не принят |
| Отправьте отчёт на mail@example.com. Код 42. | Send the report to mail@example.com. Code 42. |

Итог: 5 из 6 контрольных документов выданы без наблюдённой потери предложений и защищённых значений; 1 из 6 остановлен защитой. Это не оценка качества модели на генеральной выборке. Грамматическое качество отдельно не аттестовано. Известный проблемный текст с временем остаётся ограничением.

Runtime предупреждает об ограниченной поддержке MarianTokenizer. В повторных CPU-запусках два файла кэша модели не читались как Protobuf; их пришлось повторно загрузить. Это ограничение испытательной среды также исключает заявление об устойчивом офлайн-перезапуске.

## Автоматическая проверка и оставшаяся приёмка

`npm run check` проверяет синтаксис, прежние тесты и 20 новых сценариев целостности, включая воспроизведение сохранённых ответов моделей. Replay не загружает модель и не является новой нейронной генерацией.

Не закрыты: полная матрица 1/3 форм и обратного перевода на устройствах, живой словарь в обоих направлениях, длинные документы, корректность всех смысловых частей внутри предложения, iPhone Safari/PWA, реальное отключение сети и восстановление моделей. Модель может потерять слова внутри одного предложения без нарушения числовых инвариантов. Поэтому `stable` не возвращается; общий протокол [ACCEPTANCE_STATUS.md](../ACCEPTANCE_STATUS.md) остаётся действующим.
