# ОСЬ: техническая приёмка прототипа

Дата: 2026-09-20. Статус: локально проверенный прототип, не научная валидация.

## Контракт существующего продукта

Вход: выбор одной из пяти геометрий и одного из четырёх операторов для каждого из восьми случайно выбранных узлов. Корпус ситуаций, ключи ответов, близкие ответы, формулы изменения оси, меры, градиента и итогового балла сохранены без изменений.

Выход: обратная связь по ключам сценария, итоговый игровой балл 0–100 и попытка сохранить лучший балл на этом устройстве. Балл не измеряет личность; внешний возврат Q не наблюдается. Игра не исполняет выбранные действия вне интерфейса.

## Проверено

- Без двух выборов узел не засчитывается; переход без результата блокируется.
- Один узел учитывается один раз даже при повторном вызове обработки.
- После восьми ходов появляется итог; повторный переход не выводит индекс за пределы колоды.
- Ошибка чтения, квота, тихая потеря записи и повреждённый рекорд не скрывают результат и не сообщаются как успешное сохранение.
- Повреждённый рекорд не перезаписывается автоматически.
- Семь автоматических проверок исполняют исходный скрипт игры с имитацией DOM и хранилища.
- В локальном браузере пройден полный цикл: вводная → памятка → восемь узлов → результат 65 → подтверждение сохранения. Проверен вид итогового экрана.

## Не проверено

Реальный iPhone, системное меню отправки, недоступность буфера обмена, офлайн-запуск этой отдельной страницы, доступность для всех вспомогательных технологий и смысловая/эмпирическая валидность игровых ключей. Статус stable не присваивается.
